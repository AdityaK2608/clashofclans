# Clash Command Center

A Clash of Clans player-progress dashboard designed for GitHub Pages.

## V1

- Player Tag + API token connection UI
- Dark/light mode
- Player overview
- Town Hall, XP, trophies and league
- Heroes, troops, spells and hero equipment sections
- Progress bars and overall progress score
- Secure API adapter placeholder for a server-side proxy

### API security

Do not commit a Clash of Clans developer token to this repository. The frontend is structured so API calls can be routed through a secure backend/proxy without changing the dashboard UI.

## Local preview

Open `index.html` in a browser.

## GitHub Pages

Enable Pages for the repository from **Settings → Pages** and publish from the `main` branch.
